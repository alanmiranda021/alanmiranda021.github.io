# Missões
Modelar missões como dados e máquinas de estado, não como código de interface.

Primeira missão proposta: `propeller-obstruction`
1. Checklist pré-mergulho
2. Aproximação da embarcação
3. Inspeção da região da hélice
4. Identificação da obstrução simulada
5. Entrada na zona de intervenção
6. Confirmação da tarefa simulada
7. Relatório pós-missão

A intervenção é exclusivamente simulada até que procedimentos, restrições e segurança sejam revisados por especialistas qualificados.
