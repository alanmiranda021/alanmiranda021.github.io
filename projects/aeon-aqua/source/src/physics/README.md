# Física
Implementar modelos físicos aqui, sem dependência da renderização.

Módulos sugeridos:
- `buoyancy.ts`: peso, volume deslocado e flutuabilidade neutra
- `drag.ts`: arrasto hidrodinâmico translacional e rotacional
- `thrusterModel.ts`: curvas de empuxo e consumo elétrico
- `sixDofDynamics.ts`: dinâmica de corpo rígido e massa adicionada
- `currentField.ts`: corrente ambiental configurável

Documente unidades e crie testes unitários. O movimento inicial é simplificado, não um modelo hidrodinâmico validado.
