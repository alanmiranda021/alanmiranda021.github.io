Como usar e quais são os limites?

Envie a base, confira a variável alvo e escolha Automático ou Manual. Depois de avaliar, treine o modelo final e baixe os arquivos antes de fechar a aba. O modo automático considera poucos valores numéricos distintos como classes; use o modo manual para corrigir essa escolha.

A execução no navegador depende dos pacotes disponíveis em WebAssembly. MAT com table, MAT v7.3 e balanceamento podem ter restrições. Para bases maiores, execute a versão Python local seguindo o guia do projeto. Cada experimento utiliza um alvo.
